# Sunrise Dental Clinic Management System

A Java-based distributed application developed for managing
appointments, patients, dentists, treatments and billing
for Sunrise Dental Clinic.

## Technologies Used

- Java 17
- Maven
- Jersey REST API
- MySQL
- JUnit
- IntelliJ IDEA
- GitHub

## Main Features

- Secure user login
- Patient management
- Dentist management
- Appointment registration
- Appointment search
- Treatment management
- Bill calculation
- Help section
- RESTful web services
- Automated JUnit testing

## Database

Database name:

sunrise_dental

The SQL database script is available in:

database/sunrise_dental.sql

## Running the Application

1. Install JDK 17.
2. Install MySQL.
3. Create the `sunrise_dental` database.
4. Import the SQL file.
5. Open the project in IntelliJ IDEA.
6. Run the backend server.
7. Run the frontend application.

## API

Base URL:

http://localhost:8080/api/

## Testing

JUnit tests are included in the project to verify
the main application functionality.
